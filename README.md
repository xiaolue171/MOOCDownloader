# MOOC 下载器 2.0.2

面向 Windows 10 / 11（64 位）的中国大学 MOOC 免费公开课下载工具。
输入课程或学习页链接，选择视频与课件，按课程、章节、小节保存。

[版本发布](https://github.com/xiaolue171/MOOCDownloader/releases) ·
[反馈问题](https://github.com/xiaolue171/MOOCDownloader/issues)

## 安装与使用

安装包通过上方“版本发布”页面提供；以各版本页面实际列出的附件为准。
下载该版本 Assets 中的 `MOOCDownloader-Setup-2.0.2-x64.exe`，双击后按中文安装向导操作。
完整安装包含 Python 运行时和 FFmpeg，视频下载及合并无需另装组件。
默认安装到当前用户的应用目录，无需管理员权限；可选创建桌面快捷方式。

2.0.2 新增移除指定任务和清空下载记录，下载文件名不再附带资源 ID / 画质编号，
完成记录也不再留在课程文件夹。旧版用户关闭程序后安装新版即可，首次启动会整理
任务记录中能够确认完整的旧下载文件；失败课件任务仍可点击“重试失败”继续。

1. 在“课程资源”粘贴链接并解析。带 `tid` 的链接优先使用指定学期。
2. 点击章节、小节或资源复选框，也可全选课程、仅选视频或课件。
3. 搜索与显示筛选只改变视图，不改变已经勾选的资源。
4. 在“设置”选择保存位置、同时下载的资源数，默认 2 个。
5. 点击“加入下载队列”。在“下载任务”查看进度、速度和剩余时间。
6. 可以暂停所选或全部任务，等待状态变为“已暂停”后点击“继续队列”。
7. 失败项显示具体原因，可单独查看并重试。源站不可用或未授权的资源不会冒充下载完成。
8. 选中任务后点击“移除所选任务”，支持 Ctrl / Shift 多选；“清空下载记录”经确认后
   清空整个队列，包含当前筛选未显示的任务。运行中的任务会先停止再移除。
   两种操作都保留已下载文件和未完成进度，重新添加相同资源、画质及保存目录可跳过或续传。

默认画质策略为“高清优先”，另有“标清优先”和“最高画质”。源站的 SD/HD/SHD
是档位名称，不保证等于 360P/720P/1080P；程序在下载后读取真实视频分辨率。
源站没有提供分辨率或档位信息时，明确显示“源站默认（分辨率未知）”。

## 下载与恢复

- 直链视频和课件先写 `.part`，完成后才改为正式文件并写完整性记录。
- HLS 分片并行下载，下载与视频合并可以交错进行；视频合并不会重新编码。
- 暂停、网络故障、合并失败时保留进度；重启后任务以暂停状态恢复，不自动联网下载。
- 完整性及续传记录存放在软件数据目录的 `transfers` 中，正式文件旁不再产生 JSON。
  升级时会转移可识别的旧完成记录；未完成任务的记录会在续传时迁移。
- 文件名为“顺序号 资源名称”，例如 `01 恒星为什么发光？.mp4`；同名冲突或不同画质使用
  `(2)`、`(3)` 避免覆盖。原有未完成任务先沿用旧路径，完成后再整理名称。
- 视频来源是 FLV 时保留 `.flv`，不会仅改扩展名伪装成 MP4。
- 普通完整 MPEG-TS HLS 和带初始化片段的 fMP4 播放列表有处理路径；加密、直播、
  独立音轨或字节范围 HLS 会明确报告暂不支持，而不是输出错误视频。

并发上限可调，但下载速度也取决于网络线路和源站。没有保证多倍加速，默认不启用
未经测速证明有效的单文件多连接下载。

## 可选登录

公开课默认使用游客模式。账户入口位于“设置”，使用系统 Edge WebView2 打开独立
登录窗口，主界面不会被隐藏。登录后再次向源站验证身份，通过后才显示已登录。
登录信息由 Windows DPAPI 加密保存；独立登录进程也以加密文件传回结果，适用于没有
命令行窗口的安装版。切换账户前需要先暂停正在运行的任务。

可选登录依赖系统 WebView2 Runtime；未安装它时仍可使用游客下载功能。
课件通过资源授权接口获取 PDF 地址；《普通天文学》的首、中、末三份课件已验证可匿名
下载。其他课程若由当前资源接口明确拒绝授权，请先确认网页访问权限，必要时登录后
重试。本工具不绕过付费或权限限制。

## 文件与数据

- 默认下载目录：当前用户的 `Downloads/MOOC课程`，可在设置里更改。
- 设置、任务记录及加密账户：`%LOCALAPPDATA%/MOOCDownloader/`。
- 清空任务后仍保留 `queue-files.json` 文件关联索引及 `transfers` 完整性记录，用于再次
  添加资源时识别已有文件及续传进度。旧文件改名前会在 `backups` 中保存队列备份。
- 程序目录只存放安装文件；卸载不会删除下载的课程或个人任务数据。
- 旧版本项目目录内的 `cookies.json` 不会自动导入；需要使用账户时请在新版重新登录。

## 开发与打包

```powershell
python -m pip install -r requirements.txt
python main.py
```

源码仓库不包含 FFmpeg 二进制。请从 [FFmpeg 官方下载入口](https://ffmpeg.org/download.html)
选择 Windows 构建，将 `ffmpeg.exe` 放到 `bin/` 下。源码运行也支持从系统 PATH 查找；
生成完整安装包时必须准备 `bin/ffmpeg.exe`。公开分发所选 FFmpeg 构建前，应准备其许可证
和完整对应源码材料；本项目的源码许可证不替代第三方组件的许可。

运行 `build.bat` 生成完整安装包。需要 Inno Setup 6（默认位置或 `.tools/InnoSetup`）。
构建依赖固定在 `requirements-build.txt`，程序图标与组件声明已经随源码提供。
PyInstaller 生成文件夹版，再由 Inno Setup 统一压缩；避免单文件程序每次启动都解压。
运行时没有引入 Qt、Electron、Pillow 或单独的浏览器内核。

主要模块：

| 模块 | 职责 |
|---|---|
| `app/ui.py` | 三页界面、全局选择、事件合并与增量刷新 |
| `app/tasks.py` | 有限并发、任务状态、路径规划、视频分辨率检查 |
| `app/storage.py` | 原子保存设置与任务队列 |
| `app/downloader.py` | 完整性记录、Range 续传、HLS、可取消合并 |
| `app/transfer_state.py` | 集中存放下载元数据、旧记录迁移及文件改名恢复 |
| `app/icourse_api.py` | 课程与资源接口、学期选择、源站错误分类 |
| `app/login.py` / `app/login_ipc.py` / `app/cookies.py` | 独立登录进程、加密通信、身份验证与存储 |
| `installer/mooc.iss` | 中文、当前用户范围的 Windows 安装与卸载 |

## 验证

无需外部网络的当前版本回归：

```powershell
python -B -X utf8 tests/test_v2.py
python -B -X utf8 tests/task_removal_v2.py
python -B -X utf8 tests/ui_v2.py
python -B -X utf8 tests/layout_v2.py
```

`test_v2.py` 包括本地合成视频和真实 FFmpeg 合并，以及续传、错误状态、命名、清晰度、
学期与 Windows 加密存储检查。`ui_v2.py --preview` 可显示独立示例窗口，不会自动下载。
源码发布包保留当前版本回归和显式执行的联网测试脚本。

`tests/live_v2.py` 是需要显式执行的真实课程集成脚本，会在测试目录下载一个视频和
一份课件。`tests/live_handouts.py` 会抽测课程首、中、末三份课件，验证实际 PDF 文件。

打包后可运行 `tests/packaged_v2.py` 检查实际程序启动、WebView2 与加密登录通信。
`tests/verify_installer.ps1` 会在项目测试目录进行临时安装、启动和卸载；如果已有正式
安装则拒绝覆盖。最新修复及验证见 [2.0.2 验证报告](docs/RELEASE_2.0.2.md)，
课件与小窗口修复见 [2.0.1 验证报告](docs/RELEASE_2.0.1.md)，
初版记录见 [2.0 验证报告](docs/RELEASE_2.0.md)。

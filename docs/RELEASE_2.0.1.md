# 2.0.1 修复说明

日期：2026-10-10。

## 小窗口中的下载按钮

原因：课程列表先按自身高度占据空间，之后排列的底部操作区被挤出窗口；此前的界面
测试只检查控件能否创建，没有检查实际位置，因此未发现问题。

现在列表使用可缩小的独立网格行，底部画质选择与“加入下载队列”保留固定空间。
窗口较矮时隐藏辅助说明，为资源列表留出空间。显示筛选移至搜索栏右侧，避免挤占
选择按钮。最小窗口为 900×620，下载任务页也调整了列表和底部信息区域的布局。

新增实际 Tk 几何回归，检查按钮已显示、完整位于祖先容器内、保留正常高度，并检查
资源列表仍有可见行。以下 9 种组合全部通过：

| 字体缩放 | 900×620 | 980×680 | 1160×780 |
|---|---|---|---|
| 100% | 通过 | 通过 | 通过 |
| 125% | 通过 | 通过 | 通过 |
| 150% | 通过 | 通过 | 通过 |

证据：`tests/layout_v2.py`、`_test_tmp/layout-v2-results.json`。

## 课件无法下载

原因已确认是旧 `getLessonUnitLearnVo` 接口失效。此前仅凭这个接口的“没有权限”
返回推断首份课件不可访问，不够准确；该课程抽测课件实际可以匿名下载。

2.0.1 按照官方网页当前的文档阅读器流程获取文件：

1. 以课件单元 ID 和内容类型 3 获取资源授权，取得 `docSignDto`。
2. 用返回的文档 ID 与签名请求文档文件信息。
3. 选择 `sources` 中类型为 3 的 PDF 地址，并将网易 NOS 的旧 HTTP 地址升级到 HTTPS。

该流程已与[官方学习模块脚本](https://mc.stu.126.net/pub/s/tp_learn_index_desktop_modules_learn_content_77de50b84f45c2d14d1999790ee28ebd.js)
中的 `_fetchDocData` 和 PDF 文件选择分支核对。保留真正的授权失败提示，不会将加密
文件、Flash 或图片预览伪装成 PDF。

对用户提供的《普通天文学》进行游客身份实测：

| 样本位置 | 课件 | 下载字节数 | PDF 页数 |
|---|---|---:|---:|
| 首份 | 什么是天体物理学？ | 247,016 | 5 |
| 中间 | 恒星是如何形成的？ | 1,067,128 | 6 |
| 末份 | 什么是暴胀宇宙？ | 619,568 | 5 |

三个任务均已完成，文件头、文件尾和下载完整性记录检查通过；使用 pypdf 读取到了
上述页数。源文件包含部分无效的交叉引用项，解析器发出警告后正常读取，未修改原文件。
本次没有下载整门课，也没有使用用户账户。

证据：`tests/live_handouts.py`、`_test_tmp/handouts-v201/results.json`。

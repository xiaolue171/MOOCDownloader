# 2.0.2 更新与验证

日期：2026-10-11。

## 下载记录管理

“下载任务”页新增“移除所选任务”和“清空下载记录”。可用 Ctrl / Shift 选中多项。
清空操作需要在软件中确认，范围为整个队列，包含被当前筛选隐藏的项目。

正在下载、获取地址或合并的任务先显示“正在移除”，停止并关闭相关资源后才移除
记录；未开始的项目立即移除。其他任务继续运行。两种操作都保留课程文件及未完成
进度，不删除视频、课件或分片。

文件关联索引保存在软件数据目录的 `queue-files.json` 中，重新添加同一资源、
画质策略及保存目录时，已完成的文件自动跳过，未完成的文件继续下载。
如果关闭程序时仍有待移除记录，重启后会完成记录移除。

界面刷新以当前队列为准，防止移除前的延迟进度消息重新插入旧记录。移除后立即
重新添加同一资源时，新任务也不会被旧的排队工作线程误执行。

## 文件名称及 JSON 整理

- 新下载的文件采用“顺序号 资源名称”，例如 `01 恒星为什么发光？.mp4`。
  不再附加资源 ID 和 `-Q3`；确有命名冲突时才使用 `(2)`、`(3)` 防止覆盖。
- 下载完整性和续传信息集中放在软件数据目录的 `transfers`，完成文件旁不再留下
  `.complete.json`。HLS 分片内部元数据随成功合并一起清除。
- 启动时检查现有队列中登记的文件，迁移能够识别的旧完成记录并整理旧文件名。
  首次改名前保存队列备份；已有同名文件不会被覆盖，不相关的 JSON 不会被删除。
- 未完成的旧任务保留原文件路径以便续传，完成后再整理文件名。若改名后意外退出、
  尚未保存队列，新路径也能在下次启动恢复。

本次没有主动改动用户的实际下载目录或清空真实队列。上述旧文件整理在运行新版时
自动进行，以原队列和完整性记录能够识别的文件为范围。

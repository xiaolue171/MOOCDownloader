## 已完成的改进

### 下载与整理

独立任务引擎默认同时处理 2 个资源，可在设置中调整为 1–4 个。HLS 每个资源使用
4 个分片工作线程，整个队列最多 8 个下载请求；合并阶段限制为 1 个，允许其他资源继续
下载。延续无重新编码的快速合并方式，并增加合并取消、进度反馈和失败缓存保留。

文件先下载为临时文件，长度检查通过才成为正式文件；新增完成记录，避免将非空残缺
文件误认为已完成。支持服务器允许的断点续传，处理服务器忽略 Range、范围失效和
文件版本变化。暂停、重启及合并失败后可以继续，重启不会自动联网下载。

目录按课程、章节、小节建立，文件名包含资源 ID 和画质策略，避免同名覆盖。显式学期
链接受到尊重；清晰度选择不再混淆 HD 与 SHD，并在下载后显示实际视频分辨率。

### 界面

采用浅灰背景、白色内容区域、Windows 蓝色强调色和微软雅黑字体，分为“课程资源”、
“下载任务”和“设置”三个页面。提供全课程、视频、课件选择，以及搜索、任务状态筛选、
暂停、继续、失败重试和打开保存目录。筛选视图不会丢失已选资源；自动接续新增任务不会
重新启动用户已暂停的任务。进度、速度、剩余时间和具体错误分别呈现。

保留轻量 Tk/ttk 界面，没有引入 Qt、Electron 或额外浏览器内核。更新界面时合并频繁
进度事件并增量更新任务行，避免不断重建整张列表。

### 登录与存储

公开课默认使用游客模式，登录入口放在设置中。登录在独立进程打开，主界面继续响应；
源站身份验证通过后才显示登录成功。账户保存和进程间传递均使用 Windows DPAPI
加密，网络暂时异常不会被误判为登录失效。切换账户前需要暂停正在运行的任务。

安装版不依赖标准输出传回登录结果，已修正无控制台程序中的兼容性问题。
背景依据见 [PyInstaller 的无控制台程序说明](https://pyinstaller.org/en/stable/common-issues-and-pitfalls.html#sys-stdin-sys-stdout-and-sys-stderr-in-noconsole-windowed-applications-windows-only)。

设置、队列和加密账户保存在当前用户的应用数据目录，安装目录不承担用户数据存储。

## 真实课程抽测与限制

用户提供的 [南京大学《普通天文学》](https://www.icourse163.org/course/NJU-1001752349)
解析到 11 章、43 个视频和 43 份课件。本次仅抽测首个视频与首份课件，没有下载整门课。

- 首个视频在下载 1,179,648 字节后暂停，继续后成功得到 64,571,931 字节文件。
  实际清晰度为 960×540，时长约 500 秒。继续后的传输阶段约 82.44 秒。
- 旧版同一视频完整下载约 86.88 秒。两次测试条件及已下载字节量不同，**不能据此认定
  新版稳定提速**；该样本主要受网络传输限制，直链 MP4 不需要合并。
- 首份课件在游客模式下由源站返回“获取资源不存在或者是没有权限”。真实集成脚本因此
  如实判定未全部成功。此后已新增可读的源站错误分类并通过回归验证，未绕过访问权限。
  是否能通过实际账户访问，需要以网页端权限和登录后的结果为准。
- 未使用真实账户完成登录、授权课件下载的端到端验证。登录组件、身份校验代码路径和
  加密通信的验证不能替代真实账户测试。
- 自动窗口截图服务两次超时，未完成截图层面的视觉验收；已验证界面构建和关键交互逻辑。
- HLS 已测普通 MPEG-TS 流程；fMP4 初始化片段有处理路径，但未做真实源站全类型覆盖。
  加密、直播、独立音轨及字节范围 HLS 会明确提示暂不支持。

初始问题分析保留在 `docs/PROJECT_REVIEW_2026-10-09.md`，其中描述的是修改前状态。
